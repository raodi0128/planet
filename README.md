1. 프로젝트 개요
1.1 앱 이름
PLANET (플래닛)
Plan + Planet의 이미지 결합
사용자의 시간표, 일정, 할 일을 하나의 행성처럼 관리하는 일정 관리 애플리케이션
슬로건
나의 하루가 궤도를 그리는 곳, PLANET

───

2. 프로젝트 목적
PLANET은 대학생 및 일반 사용자를 위한 시간표 + 일정 + 할 일 통합 관리 애플리케이션이다.
기존의 시간표 앱은 수업 일정 관리에 집중되어 있고, 일반 플래너 앱은 개인 일정과 할 일 관리에 집중되어 있다.
PLANET은 이러한 기능을 하나의 애플리케이션에서 제공하여 사용자가 자신의 하루와 계획을 한눈에 관리할 수 있도록 한다.
핵심 목표
• 시간표 관리
• 개인 일정 관리
• 할 일 관리
• 계획 진행률 확인
• 알림 기능
• 통계 제공
• 직관적이고 감성적인 UI 제공

───

14. 프로젝트 개발 목표
PLANET은 단순한 시간표 앱이 아닌,
시간표 + 일정 + 할 일 + 계획 관리
를 하나로 통합한 개인 플래너 애플리케이션을 목표로 한다.
사용자는 자신의 하루를 하나의 궤도로 관리하며, 오늘 해야 할 일을 직관적으로 확인할 수 있다.
최종 목표
